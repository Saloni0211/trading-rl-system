# 🚀 ML + RL Trading System

## 📌 Overview
This project implements a Machine Learning + Reinforcement Learning based trading system that:
- Learns market patterns from OHLCV data
- Uses clustering to identify market regimes
- Trains an RL agent to make trading decisions

---

## 🧠 Features
- 📊 Feature Engineering (returns, volatility, moving averages)
- 🤖 Unsupervised Learning (Autoencoder + KMeans)
- 🎮 Reinforcement Learning (PPO Agent)
- 📉 Custom Trading Environment
- 📈 Performance Metrics (Sharpe Ratio, Drawdown)
